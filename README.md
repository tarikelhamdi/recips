# Mobile Games Email Template

Professional HTML and CSS email template for marketing mobile games.

## 📧 Email Template Features

- **Professional Design**: Dark gaming theme with vibrant gradient accents
- **Mobile Responsive**: Optimized for all device sizes
- **Email Client Compatible**: Uses inline CSS and table-based layout for maximum compatibility
- **Gaming Focused**: Showcases 4 featured mobile games with dedicated sections

## 🎮 Featured Games

1. **GTA 5 Mobile - Last Update** - Enhanced graphics and new missions
2. **GTA 4 Mobile** - Liberty City experience on mobile
3. **Call of Duty: Black Ops 6 Mobile** - Multiplayer action and zombies mode
4. **God of War: Ragnarök Mobile** - Epic Norse adventure with Kratos and Atreus

## 📱 Template Structure

- **Header**: Gaming brand with gradient background
- **Welcome Section**: Engaging introduction message  
- **Game Showcase**: Individual cards for each featured game
- **Call-to-Action**: Primary download button
- **Footer**: Contact information, social links, and unsubscribe options

## 🛠️ Technical Features

- HTML5 with inline CSS for email compatibility
- Table-based layout for consistent rendering
- Mobile-first responsive design
- Professional typography and color scheme
- Email marketing compliance (unsubscribe links)

## 📁 Files

- `mobile-games-email-template.html` - Main email template
- `preview.html` - Preview page for testing

## 🚀 Usage

Open `mobile-games-email-template.html` in any email client or web browser to view the template. The design follows email marketing best practices and is ready for use in email campaigns.
